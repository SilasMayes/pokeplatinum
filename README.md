# Builds

Ready-to-run builds of the `thor-android` branch, one folder per build. The same files are
attached to the [releases](https://github.com/SilasMayes/pokeplatinum/releases).

Code only: no game files. On first launch each build asks for your own dump of Pokémon
Platinum (USA, CPUE01) and extracts it.

This branch has no history in common with the source branches; it only holds the build files.
